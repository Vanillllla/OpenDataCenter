# Logical network — 0.6.1.3-alpha

- LAN T1 (100 Mbps, серый, прежний ID `ethernet_patch`), T2 (1000 Mbps, синий), T3 (100000 Mbps, фиолетовый). Рецепты не изменены; новые уровни доступны в творческом меню.
- В стойке: выберите уровень кабеля, порт, затем юнит сервера. Для замены выберите порт и более высокий уровень, нажмите «Заменить». Номинал кабеля, NIC и существующий предел порта независимы. Старый вычислительный путь ограничен минимумом этих трёх значений; новый WAN пока не используется.
- В сетевом терминале: выберите коммутатор в списке, уровень кабеля, затем «Соединить», «Отключить» или «Заменить». Действия адресуются по UUID, не по номеру строки. Для создания и модернизации требуется подтверждённый физический LAN и права на оба устройства; для отключения ранее созданного uplink достаточно прав на терминал. Одна связь на пару терминал–коммутатор, несколько разных терминалов разрешены. Разорванные соединения видны со стороны своего терминала и могут быть отключены. Полноценная карта — Stage 5/6.
- `PhysicalNetwork.logicalView(world, origin)` возвращает `LogicalLinks.Link`: UUID, endpoints, kind, tier, nominal capacity, state, usedMbps. FIBER строится из физического графа, стабильный ID вычисляется из пары устройств. PATCH строится по фактическому порту и его постоянному ID (хранится в NBT стойки). UPLINK хранится отдельно в WorldSavedData и не исчезает при разрыве Data Cable. Состояние пересчитывается из физической доступности и питания, а не восстанавливается как гарантированно активное из сохранения. Загрузка активных связей неизвестна (-1) до Stage 4; это не измеренный трафик.
- Патч-корды возвращаются по исходному уровню при отключении, разборке и объединении стойки (как раньше, её локальные патчи сбрасываются при изменении 4U/9U). Uplink сохраняется при перемещении остающегося коммутатора в другой юнит при объединении стойки; при удалении коммутатора или терминала связанные кабели выпадают. Устройство, удалённое штатным игровым способом, очищает связи один раз. При временной выгрузке ничего не возвращается.
