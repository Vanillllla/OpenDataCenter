# Workbench hotfix — проверка в Minecraft 1.12.2

Сборка: JDK 8, Forge 14.23.5.2860, `build.bat` (Windows) или `bash build.sh` (Linux). Gradle `verifyWorkbenchTransfers` входит в `check`. Для проверки отдельно после подготовки Gradle wrapper: `gradlew.bat verifyWorkbenchTransfers`.

- В режиме выживания положить в стол пустой корпус, подходящую плату и взять **одну** планку RAM из инвентаря обычным ЛКМ. Поставить её в первый слот DIMM. Курсор должен быть пуст. Нажать ЛКМ по второму слоту — второй предмет не появляется. Повторить с ПКМ.
- Забрать компонент обычным кликом и через Shift+ЛКМ; количество предметов в корпусе, инвентаре и на курсоре в сумме не меняется. Повторить с несколькими RAM в одной стопке и заполненным инвентарём.
- Проверить CPU, накопители, PCIe-устройства и БП, замены совместимых деталей, отказ при несовместимой детали, защиту установленной платы с компонентами. Горячие клавиши и перетаскивание по нескольким аппаратным слотам по-прежнему заблокированы.
- Извлечь собранный корпус обычным кликом и Shift+ЛКМ, вставить обратно. Его NBT сохраняет компоненты ровно в одном экземпляре.
- Положить 1U, 2U, 4U по очереди; закрыть GUI и проверить модель корпуса на столе. После извлечения модель исчезает. Проверить четыре направления размещения стола, перезагрузку мира, выгрузку чанка и видимость для другого игрока.
- На выделенном сервере с задержкой сети повторить быстрые клики и Shift+ЛКМ. Другой игрок не должен иметь доступ к одновременно открытому столу. Сломать стол после закрытия GUI: выпадает ровно один корпус с установленными компонентами.

Реализация использует четыре состояния модели (пустой стол, 1U, 2U, 4U), выбираемые из фактического слота. Это динамическая смена модели без отдельной сущности-предмета и без плавного перемещения корпуса. Старые коллизии блока оставлены без изменений.

Проверка в среде подготовки: `tools/validate_assets.py` и `tools/test-core.sh` пройдены. Полноценная Forge-сборка и `verifyWorkbenchTransfers` не выполнены: JDK 8 отсутствует, зависимости Forge недоступны по сети. Игровая проверка не выполнена.
