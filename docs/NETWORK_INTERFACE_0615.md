# 0.6.1.5 — Network Terminal Interface

## Открытие и управление

ПКМ по сетевому терминалу открывает карту. ПКМ по антенне открывает прежнее окно информации. В карте: колесо над схемой масштабирует относительно курсора, `+`/`-` масштабируют относительно центра, перетаскивание пустой области или ПКМ/СКМ перемещает камеру. «Вся сеть» вписывает схему, «Найти» центрирует выбранный узел; выбор из списка также находит узел. Поиск работает по имени, модели и координатам; Escape снимает фокус с поиска. Колесо и ползунки в боковых панелях прокручивают их содержимое. Кнопка «Настройка uplink» открывает прежнее списочное окно, «Карта» возвращает в карту. Это не графический редактор — он относится к 0.6.1.6.

Сетевые устройства располагаются по четырём горизонтальным уровням. Карточки показывают модель, имя, состояние, занятую и номинальную полосу; в панели свойств есть свободная полоса, LAN/WAN, модель быстрейшего NIC, подключённые устройства и диагностические ограничения. Оранжевый — оптика, серый/синий/фиолетовый — LAN T1/T2/T3. Недоступные связи серые, при достаточном масштабе пунктирные. При сильном уменьшении отображение упрощается; чтобы прочитать данные, приблизить карту или выбрать устройство. Физический Data Cable не рисуется.

## Данные и расчёт

`NetworkMapView` строит снимок на серверной стороне по `PhysicalNetwork.view`, `logicalView` и единому `BandwidthEngine.Result`. `NetworkMapPackets` отправляет заголовок, пачки максимум по 48 записей, и завершение. Клиент принимает пакеты только для открытого окна сетевого терминала; цельный снимок заменяет предыдущий после сверки числа записей. Сервер проверяет `canInteractWith`, обновляет до одного раза в секунду и не отправляет неизменившиеся снимки. Число конкретных причин-UUID на узел ограничено 128; полное число ограничений отдельно показывается. Никаких клиентских команд изменения карты на этом этапе нет.

`NetworkMonitor` ограничивает топологию физической LAN и её оптическими источниками. Если логическая связь выходит за границу текущего домена после разделения, она учитывается в счётчике недоступных связей, без передачи удалённого узла/линии. Загрузка общей антенны глобальна для измерения. WAN used — сумма обслуженного WAN на верифицированных терминалах этого домена. Free at ingress — дополнительная ёмкость на входах терминалов при текущих фиксированных маршрутах: max-flow по остаточным ёмкостям антенн, оптических связей и терминалов. Не является гарантированной свободной полосой на сервере, не учитывает перераспределение уже обслуженных маршрутов; для этого нужна интеграция с admission на этапе 7. LAN — сумма обслуженных локальных запросов между верифицированными серверами домена, без суммирования последовательных устройств. Действующие контракты пока создают только WAN-запросы. Нагрузка отражает проекцию резервов, а не измеренный трафик. Неизвестные данные помечаются `?`, непроверенные части карты отмечаются.

`NetworkMapLayout` хранит UUID-позиции карточек и камеру в рамках открытого окна. При новом снимке выжившие карточки остаются на местах; новые занимают свободные места, удалённые исчезают. Поиск и выбранный UUID не сбрасываются, пока объект существует. Сохранение ручной раскладки между открытиями/терминалами — этап 6. Длинные линии обрезаются областью карты; мелкие масштабы используют упрощённую отрисовку.

## Проверка

`tools/test-core.sh`: все автономные тесты пройдены, включая `NetworkMonitorTest` (68 573 проверки): общие антенны, область видимости, остаточная WAN-ёмкость, локальный трафик и причины, 420 устройств, вписывание, попадание курсора, сохранение положения и масштабирование. `tools/validate_assets.py`: 27 660 проверок. Синтаксический разбор всех Java-файлов без ошибок. Полная типовая компиляция Forge 1.12.2, игровой рендер, реальная доставка пакетов, GUI Scale и ручные проверки не выполнены: среда содержит JDK 21 без необходимых зависимостей Forge/JDK 8.

Ручная проверка: создать сеть с двумя терминалами, общей антенной, несколькими коммутаторами и LAN-кабелями разных уровней. Создать uplink в списочном интерфейсе, вернуться в карту. Проверить линии, свойства, поиск, масштаб, обрезку панелей, обновление нагрузки, удаление/восстановление Data Cable и выгрузку чанка. Проверить 2 клиента и разные GUI Scale. Старый механизм запуска/оплаты не изменён.
