## Приёмочные тесты 0.2.1 (в игре)

1. Сборка: `test-core.bat`, `build.bat`, новый творческий мир. Проверить шесть новых предметов и их рецепты.
2. Пустой корпус 1U: положить только корпус в станок, нажать «Собрать», извлечь предмет сервера; вставить в стойку. В меню «Детали» отсутствуют плата/CPU/RAM/диск. Он занимает 1U, не зарабатывает NTC.
3. Последовательно установить плату, CPU, RAM, диск. После каждого шага статус должен показывать следующий отсутствующий компонент; после последнего — готовность. Установить CPU-only банк, проверить работу при питании, WAN, LAN и включённой задаче.
4. Открыть «Детали» у работающего банка: сервер прекращает расчёт, индикатор гаснет. Другие серверы продолжают работу. Извлечь диск и закрыть GUI: задача не возобновляется. Вернуть диск, закрыть GUI: прежнее назначение снова выполняется.
5. Собрать 4U с Pro Motherboard, четырьмя RAM 16 GB, двумя SSD и четырьмя GPU T2. GUI показывает 64 GB RAM, 1024 GB Disk, 64 GB VRAM. Проверить майнинг и AI. Понизить плату до Basic: лишние детали остаются, но запуск запрещён. Извлечь их либо вернуть Pro.
6. Проверить слоты: нельзя положить CPU в RAM, второй диск в 1U, второй GPU при Basic Motherboard. Проверить обычный клик, shift-click, клавиши хотбара и перетаскивание стеков; предметы не дублируются, не исчезают и не занимают недопустимый слот.
7. Извлечь полностью собранный сервер, переложить в другую стойку: все комплектующие сохраняются, назначение задачи сбрасывается. Перезайти в мир, повторно проверить содержимое. Разрушить стойку во время обслуживания в тестовом мире: выпадает единственный сервер с актуальными деталями; старый GUI не позволяет извлекать копии.
8. Мультиплеер: два игрока с правами владельца/creative пытаются открыть один сервер; второе редактирование блокируется. Пока один обслуживает, второй не может извлечь или заменить этот сервер через интерфейс стойки. Проверить закрытие GUI, разрыв соединения, смерть, выход за радиус действия, разрушение блока.
9. Миграция (отдельная резервная копия 0.2.0): старый CPU и количество GPU сохранены; новые детали отсутствуют. Установить плату, RAM, диск, перезагрузить мир и сравнить инвентарь. Содержимое старого станка не должно переместиться в другие слоты. Проверить баланс и назначения.
10. Повторить сетевые/энергетические тесты из `TEST_REPORT_0.2.0.md`, особенно доход без ресурса, разрыв кабеля и общую пропускную способность.

## Известные ограничения

Одна задача на физический сервер. RAM и диски пока не влияют на вычислительную производительность, имеют условные ёмкости и номинальные частоты. БП/NIC, охлаждение, произвольные задачи, новые интеграции не входят в этот релиз. Состояния LED отражают выполнение вычислительной задачи, а не отдельный режим питания/простоя. Сетевые и экономические упрощения 0.2.0 сохранены.
