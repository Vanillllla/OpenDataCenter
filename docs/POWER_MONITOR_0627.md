# Power Monitoring 0.6.2.7

Read-only DataOS tab 5, using the existing authenticated window request and snapshot packet. The server determines visible grids from the same-owner loaded LAN and verified optical connections, deduplicates physical domains and scopes navigation to that list. A selected grid describes its full physical electrical domain, not just the subset of equipment belonging to this LAN. Shared electrical domains are not counted twice and separate grids are not summed. Unverified/unloaded remote LAN fragments are not claimed. A fully unpowered DataOS still has its existing black-screen behavior.

The scheduler publishes completed samples after power and task settlement. Creative rated supply is confirmed when active; HE/FE capacity is only the paid receipt available for this cycle, never the external transformer's nameplate or an estimate of third-party headroom. Free confirmed watts = max(0, confirmed supply - actual load). Nominal ratings are shown separately. Actual loads use powered masks, actual rack watts and fixed equipment ratings. Virtual loads use the same funded group budget, plus a stored fixed category breakdown; old snapshots without this optional breakdown show fixed load as Other until recaptured. No change to external API or simulation rules.

History: 120 samples at 100 ticks, up to 12000 ticks (ten simulated minutes); latest readings update each cycle. Exact dimension/footprint keys separate split/merged grids. A bounded in-memory cache of 512 histories per world expires inactive histories; no persistence across server restart. Missing/unknown samples break lines rather than pretending that the entire grid supplied zero. Partial topology is labeled and total supply/spare are not shown as verified. With requireEnergy=false, supply has no modeled cap and is not displayed as a finite number.

Selected grid only, 32 paged source rows per packet, no individual-server list. Existing DataOS GUI scaling and scissor/scroll system retained. No new monitoring gameplay, forecasts, maps or controls.

Manual checks: two independent power grids on one LAN, shared electrical network across LANs, linked antenna and tower, creative battery and HE/FE transformer, no external reserve inference, off/tripped network while another powers DataOS, no history at first open, ten-minute history, topology split/merge, more than 32 sources, small GUI scale, Russian and English, dedicated server synchronization and permissions. Actual Minecraft checks have not been performed.
