# OpenDataCenter 0.3.0-alpha — отчёт проверки

## Выполненные проверки

Среда: OpenJDK 21.0.12.1; исходники чистой Java-компоненты скомпилированы `javac -source 8 -target 8`. `JavacTask.parse()` проверил синтаксис всех Java-файлов без анализа типов Minecraft. ForgeGradle build остановился на проверке JDK 8; `curl` не смог разрешить maven.minecraftforge.net. Это **не** подтверждает полную компиляцию или работу в игре.

Фактический вывод тестов:

```
PASS: 1613018 mining/energy/network assertions; 20000 random scenarios; topology loops/overflow.
PASS: 261776 hardware/layout assertions; 30000 random hardware configurations; 2760 valid 9U layouts; 30000 patch operations.
PASS: 3812 resource checks; 12 block types; 28 item types; 38 recipes; 70 PNG textures; 24 rack frame variants; 384 cable/relay states.
PASS: Java 8 syntax parsed for 18 Java files (no Forge type resolution).
```

Проверки покрывают новое производственное математическое ядро майнинга, локальный switch/NIC/порт, общий WAN, FE бюджет, целочисленное распределение, отсутствие награды без работы, сетевые петли и превышение лимита поиска. Проверено 2760 геометрически допустимых вариантов 9U, пересечения, сохранение только целых устройств при разделении, обязательные компоненты, 30 000 случайных аппаратных конфигураций и 30 000 операций портов с сохранением числа кабелей. В ресурсах проверены ссылки JSON, текстуры, размеры, рецепты, 24 варианта рамок и 384 состояния кабелей/реле. Эти тесты **не исполняют** Forge-контейнеры, TileEntity, реальное перемещение предметов, Minecraft-рендеринг, NBT в сохранённом мире или Redstone.

## Приёмочные проверки в Minecraft (не выполнены)

### Сборка и загрузка
- [ ] `.\test-core.bat` и `.\build.bat` завершаются успешно с JDK 8 и stable_39.
- [ ] Клиент и dedicated server запускаются без ошибок регистрации/моделей.
- [ ] Новый мир и вкладка OpenDataCenter; все 12 блоков и 28 предметов видимы.
- [ ] Ни одного фиолетово-чёрного missing model; читаемые EN/RU названия.

### Рабочий стол
- [ ] Пустой корпус 1U/2U/4U помещается в рабочий стол, извлекается без кнопки сборки.
- [ ] Добавить/извлечь каждый тип детали обычным кликом и Shift-кликом, затем вынуть корпус; его подсказка показывает правильную конфигурацию.
- [ ] Для Advanced board в 1U доступны 8 RAM, 8 SATA, 2 NVMe, один GPU и один PSU.
- [ ] PSU и GPU 2U/4U ограничены размерами 2/4; SATA/NVMe не взаимозаменяемы.
- [ ] Отсутствие платы/CPU/RAM/диска/PSU оставляет корпус неполным; GPU необязательна.
- [ ] NIC необязателен для комплектности, обязателен для сети.
- [ ] Нельзя снять плату с зависимыми компонентами, нельзя положить неподходящие детали.
- [ ] Извлечение корпуса, повторная установка, перезапуск мира и разрушение рабочего стола сохраняют все комплектующие ровно один раз.
- [ ] Два игрока не могут одновременно изменять один рабочий стол; воронки не обходят ограничения.

### Стойки
- [ ] Две рамки одного типа и направления объединяются, GUI обеих показывает один инвентарь 9U.
- [ ] Третья рамка не объединяется с парой; четвёртая создаёт новую пару. Разные типы/направления не объединяются.
- [ ] Можно ставить 4U+1U+4U, 2U через центральный слот, произвольные свободные позиции.
- [ ] Второй switch в одну стойку не принимается. В 4U с 4U сервером невозможно установить switch.
- [ ] Сломать верх/низ в отдельных тестах: сохраняются только модули, помещающиеся в оставшиеся 4U; центральные/пересекающие выпадают целыми, без потери вложенных деталей.
- [ ] После объединения/разделения все прежние патч-кабели возвращаются ровно по одному за соединение; открытые старые GUI закрываются.
- [ ] 1U, 2U, 4U имеют визуально разные цельные панели. Стекло и ручка не пересекаются. LED включения, отключения, работы и портов соответствуют состоянию.

### Сеть
- [ ] Вставить switch T1/T2. Выбрать порт, нажать `+P` на сервере с NIC; потрачен 1 Patch Cable.
- [ ] Нельзя подключить сервер без NIC, дважды использовать порт или один сервер, использовать 5-й порт T1, использовать чужую стойку.
- [ ] Отключение кнопкой возвращает кабель в инвентарь; извлечение оборудования возвращает связанные кабели в мир.
- [ ] При полных инвентарях возврат кабеля выпадает; проверить сохранение после перезахода.
- [ ] Два терминала показывают общий кластер и не удваивают доход. После перестановки серверов обновить список терминала.
- [ ] Radio/Satellite дают 128/512 Mb/s при питании; без питания WAN не добавляется.

### Электрика и майнинг
- [ ] Data и Power Cable не пропускают игрока сквозь центральную часть/ответвления, но не создают невидимую полноблочную стену.
- [ ] Соседние отдельные стойки делятся данными, не делятся питанием. Для 9U питание любой половины работает.
- [ ] Redstone реле отключает путь питания; параллельная линия при наличии сохраняет питание. Без Redstone цепь восстанавливается.
- [ ] Выключенный сервер не потребляет мощность, включённый потребляет базовую, switch потребляет собственную.
- [ ] Через терминал включить сервер, назначить Mine, проверить хешрейт CPU-only и CPU+GPU, доход в NTC.
- [ ] Отключение кабеля, реле, NIC-соединения, WAN, терминала или обязательного питания прекращает начисление в следующем цикле; LED гаснет. Проверить включение после восстановления.
- [ ] Магазин списывает NTC ровно один раз и отдаёт правильный предмет. Баланс и оборудование сохраняются после перезапуска нового мира.

## Не покрыто / перенесено

Глобальное вычисление выгруженных чанков, динамические ограничения PSU, полноценный диспетчер и новая DataOS — 0.4.0. Синтаксический анализ не выявляет несовпадения сигнатур Forge/MCP, поэтому при первой компиляции возможны дополнительные исправления. Предпросмотр в `preview.png` — отдельный рендер моделей/текстур, не игровой скриншот; полупрозрачная панель стекла показывается только клиентским рендерером в Minecraft. Производительность большого зала с динамическими рендерами ещё не измерена.
